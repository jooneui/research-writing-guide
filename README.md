# Research writing guide

A portable set of instructions for research papers and weekly meeting notes. Copy the prompt in `PROMPT.md` into a writing request, or point a writing assistant to this repository.

## Core rule

For each **substantive item**, state its purpose, why that purpose matters, and the concrete deliverable. For each **factual or interpretive claim**, give a reason and traceable evidence. A planned deliverable is not evidence that a result already exists.

Use one technical term for one concept. Keep sentences short and specific. State uncertainty and missing evidence plainly.

## Files

- [PROMPT.md](PROMPT.md): reusable instructions for a writing assistant.
- [MEETING_NOTE_TEMPLATE.md](MEETING_NOTE_TEMPLATE.md): itemized weekly note with labeled bullets.
- [PAPER_TEMPLATE.md](PAPER_TEMPLATE.md): research paper planning and drafting scaffold.
- [TURABIAN_NOTES.md](TURABIAN_NOTES.md): the book-based rationale and section references.

## Use

1. Clone this repository and provide `PROMPT.md` with the source files, figures, data, and intended audience.
2. Specify `meeting note` or `research paper` and give the current project question.
3. Review the result against the source files, especially numbers, figure labels, and citations.

The prompt supports your preferred structure. Follow a journal, conference, advisor, or university format when one applies. The book itself says local requirements may take precedence over its format guidance.

The source PDF is kept outside this repository. Do not upload the book with this guide.
